Detailed Description

module to process the ADC values

The module for now consist of the IPROPI from the motor driver [https://tinyurl.com/MODRV], VBUS [Schematics], Temperature from Thermistor : TFET [https://tinyurl.com/TFET0] TMOT [https://tinyurl.com/TMOT0]
